## Melaporkan Kerentanan Keamanan

Jika Anda menemukan celah atau kerentanan keamanan pada template ini (misalnya celah kebocoran data formulir atau sanitasi input):

1. **JANGAN** membuat isu publik di GitHub Issues.
2. Silakan laporkan secara privat melalui fitur **Security Advisories** di tab "Security" repositori GitHub ini, atau kirim email langsung kepada pengelola proyek: `faliqulishbah@gmail.com`.
3. Sertakan informasi berikut dalam laporan Anda:
   - Deskripsi kerentanan.
   - Langkah-langkah untuk mereproduksi masalah (Proof of Concept).
   - Dampak potensial terhadap data sekolah atau siswa.

Tim pemelihara akan meninjau laporan Anda dalam kurun waktu 1–3 hari kerja dan merilis perbaikan sesegera mungkin.
